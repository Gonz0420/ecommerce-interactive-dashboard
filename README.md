## 💡 Resumen del Proyecto
Desarrollo de una aplicación web analítica e interactiva diseñada para la exploración visual de ventas cross-channel, hábitos de consumo por día de la semana y segmentación demográfica (Edad, Género, País) para la optimización de campañas de Performance Marketing (Meta Ads / Google Ads).

---

## 🎛 Funcionalidades Interactivas
* **Filtros Dinámicos en Tiempo Real:** Segmentación cruzada por Día de la Semana, Categoría de Producto, Rango de Edad, Género y País.
* **KPIs Dinámicos:** Recálculo automático de Ingresos Netos, Transacciones Totales y Ticket Promedio según la combinación de filtros activa.
* **Análisis de Rendimiento por Canal:** Medición de atribución en tiempo real entre Website, Mobile App y Social Media.
* **Cross-Analysis Demográfico:** Visualización apilada por rango etario y género para perfilar buyers persona.

---

## 🛠 Tecnologías Utilizadas
* **Frontend / Dashboard:** HTML5, Tailwind CSS, JavaScript (React / Recharts)
* **Despliegue:** GitHub Pages
* **Procesamiento de Datos previo:** Python (Pandas)
